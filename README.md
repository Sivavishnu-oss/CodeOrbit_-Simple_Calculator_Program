# Java Calculator

A simple console-based calculator application built in Java. It supports basic arithmetic operations through an interactive menu-driven interface, with robust exception handling for invalid input and division/modulus by zero.

## Technologies Used

- Java (JDK 8+)
- `java.util.Scanner` for console input
- `java.util.InputMismatchException` for input validation

## Features

- Addition, Subtraction, Multiplication, Division, and Modulus operations
- Interactive menu loop that runs until the user chooses to exit
- Handles invalid (non-numeric) input gracefully
- Handles division/modulus by zero with clear error messages

## Setup Instructions

1. **Install Java**: Ensure you have JDK 8 or later installed. Verify with:
   ```
   java -version
   javac -version
   ```

2. **Compile the program**:
   ```
   javac Calculator.java
   ```

3. **Run the program**:
   ```
   java Calculator
   ```

4. **Using the calculator**:
   - Select an operation (1–6) from the menu.
   - Enter the first and second numbers when prompted.
   - View the result, or an error message if input is invalid.
   - Select option `6` to exit the program.
